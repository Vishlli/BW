# 3-minute demo script

1. **0:00–0:25 — Set the context:** “BatteryWise compares pack configurations using one calculation engine, one load profile, and traceable assumptions.”
2. **0:25–0:55 — Beginner mode:** choose the NMC baseline; show energy, cell-only mass, and the peak-temperature estimate.
3. **0:55–1:25 — Intermediate mode:** compare NMC and LFP configurations and explain the mass/energy trade-off.
4. **1:25–2:00 — Conflict explorer:** open a violated or unresolved check; show its input, reason, and suggested next step.
5. **2:00–2:30 — Advanced/Expert:** inspect interconnect resistance and segment-by-segment thermal state; download JSON/CSV.
6. **2:30–3:00 — Evidence and limits:** show reference cases and test results. Clearly identify what is calculated, verified, measured, or still unresolved.

Do not present the illustrative values as measured evidence. Record the actual test command and output after running the suite.
